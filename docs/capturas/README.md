# Capturas de pantalla

Transcripciones reales de la terminal (salida UTF-8 de `python main.py`),
generadas para la demo y la defensa (TP10):

| Archivo | Contenido |
|---|---|
| `demo-10-top-n.txt` | Opción 10 — Ranking Top 5 con la MaxHeap (medallas 🥇🥈🥉) |
| `demo-11-categorias.txt` | Opción 11 — Jerarquía de categorías con conteos + búsqueda de categoría + juegos de Roguelike |
| `demo-12-grafo-bfs-dfs.txt` | Opción 12 — Juegos relacionados, consulta BFS (más cercano) y exploración DFS de la red |

Para regenerarlas:

```bash
python main.py < entrada.txt > docs/capturas/salida.txt 2>&1
```
